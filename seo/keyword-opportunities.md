# Keyword Opportunities — US Web Development Agency

Data source: Ubersuggest (connected MCP), US location (Google location ID 2840), retrieved 2026-10-23. Full raw data in [`keyword-research-us.csv`](keyword-research-us.csv); page assignments in [`keyword-mapping.csv`](keyword-mapping.csv).

**Note on search intent:** the Ubersuggest API returns intent as numeric codes. This report labels them "commercial" / "transactional" / "unavailable" based on the connector's own field names, but the exact code-to-label mapping is not independently confirmed — treat the intent labels as directional, not authoritative. Volume, SD (SEO Difficulty), PD (Paid Difficulty), and CPC figures are measured data from the connector, not estimates.

## Top opportunities (ranked by realistic near-term value)

1. **wordpress web design agency** — 1,900 vol / SD 7 — the single best difficulty-to-volume ratio found in this research. Only pursue if WordPress development is a genuinely delivered service.
2. **website development company** — 4,400 vol / SD 15 — highest-volume head term with low difficulty; strong home-page target.
3. **ecommerce website development firm** — 590 vol / SD 8 — low difficulty, and the broader ecommerce cluster carries very high CPC ($23–$190), indicating high-value leads.
4. **ecommerce website redesign services** — 590 vol / SD 7 — same cluster, same reasoning.
5. **website maintenance services** — 2,400 vol / SD 21 — solid volume/difficulty balance, and a natural retainer offer once a client's project ships.
6. **ecommerce website development** — 1,300 vol / SD 23 — the primary (highest-volume) term in the ecommerce cluster; CPC of $96.93 signals strong commercial value.
7. **web application development services** — 1,300 vol / SD 30 — highest CPC found ($87.74); moderate difficulty makes this a medium-term target rather than a launch-day win.
8. **website redesign services** — 6,600 vol / SD 35 — second-highest volume in the whole research set; harder to rank for than the items above but worth building toward.
9. **web design agency** — 12,100 vol / SD 33 — the single highest-volume keyword found; difficulty is moderate, so treat this as the services-hub target rather than expecting a quick win.

## Deprioritized or excluded

- **Location-specific terms** (e.g. "web design agency new york," "website development company denver," "web design agency near me") were excluded. Per the execution rules, the agency has no genuine local office presence, so building doorway pages for these would misrepresent the business.
- **International terms** (India, Dubai, UK, Australia, etc. — a large share of the ecommerce and web-app clusters) were excluded as out of scope for a US-focused site.
- **"Best"/"top" superlative queries** (e.g. "best website development company," SD 63) were deprioritized — high difficulty with no guarantee of a defensible ranking position for a new domain.
- **Shopify-specific terms** returned limited confirmed data (most suggested Shopify keywords had no measurable volume). Treat Shopify as a lower-confidence opportunity until more data is available or the site is live and generating its own Search Console data.
- **"SEO and web design agency" / "SEO web design agency"** were excluded — out of scope, since the business is web development only, not a marketing agency (per the execution rules).

## What still needs verification before publishing

- Which of these services (ecommerce, custom web apps, WordPress, Shopify, maintenance) the business can **actually deliver** — do not build a service page for a capability that isn't real.
- The final domain and brand name, which affects the exact canonical URLs used throughout this report and the mapping CSV (currently placeholders).
- Real portfolio projects, case studies, and any testimonials — none were available at research time, so none were fabricated.
